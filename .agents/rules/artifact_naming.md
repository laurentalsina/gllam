# Rule: Specific Artifact Naming

Always use descriptive, origin-specific filenames when creating markdown artifacts or reports.

- **DO NOT** create generic filenames like `walkthrough.md`, `plan.md`, `notes.md`, or `report.md`.
- **ALWAYS** include the specific task or issue identifier in the filename (e.g., `issue_1_walkthrough.md`, `issue_2_implementation_plan.md`, `pddl_compiler_analysis.md`).
- This ensures historical clarity and prevents artifacts from overwriting each other across multiple tasks or subagents.
